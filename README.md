## 🌟 Key Highlights & Features

1. **⚡ Interactive Live BI Analytics Cockpit**:
   - Built with **Recharts** for real interactive data visualization directly in the browser.
   - **Revenue & Target Trajectory**: Area charts with custom KPI metrics and toggleable forecast projections.
   - **RFM Customer Segmentation**: Interactive donut chart breaking down 500k+ transactions into VIPs, Loyalists, and At-Risk accounts.
   - **AWS Cloud Infrastructure Telemetry**: Real-time 24-hour CPU, memory, and latency curves.
   - **Competency Radar**: Full-spectrum visual evaluation of SQL, Python, Power BI, AWS, and Terraform proficiency.

2. **☁️ Cloud Data Pipeline & Architecture Visualizer**:
   - Interactive 5-stage architectural explorer:
     1. Ingestion & Streaming (PostgreSQL CDC, APIs, AWS CloudWatch)
     2. Cloud Storage & Lakehouse (AWS S3 partitioned buckets, KMS SSE-C)
     3. ETL Wrangling & Orchestration (Python, Docker, Terraform, Jenkins)
     4. Data Mart & Modeling (PostgreSQL Star Schema, Materialized Views)
     5. Executive BI Dashboards (Power BI DAX scorecards)

3. **📁 Filterable Featured Projects & Case Studies**:
   - Filter by **"All"**, **"Data Analytics"**, and **"Cloud & DevOps"**.
   - Includes real GitHub repositories:
     - 🛒 *E-Commerce Customer Segmentation & RFM Analysis* (500k+ rows)
     - 📊 *Executive Sales & Revenue KPI Dashboard* ($4.2M analyzed, DAX)
     - 💳 *Financial Transactions & Fraud Anomaly Detection* (92% precision)
     - ☁️ *AWS Multi-Tier VPC & Cloud Infrastructure* (Terraform HCL)
     - 🖥️ *Automated Cloud Server & Health Monitor* (Python daemon)
     - 🔄 *Cloud CI/CD DevOps Pipeline* (Jenkins & Docker)
     - 👥 *HR Workforce Analytics & Employee Attrition Study*
   - Interactive **Case Study Modal** detailing the Business Problem, Technical Solution, Quantified Impact, and key code snippets.

4. **💻 SQL & Cloud Code Showcase**:
   - Interactive multi-tab code viewer with one-click clipboard copying.
   - Highlights production **SQL CTEs & Window Functions**, **Python Data Cleaning & IQR Outlier Sanitization**, and **Terraform AWS VPC IaC** scripts.

5. **👤 Authentic Profile & GitHub Stats**:
   - Integrated live GitHub analytics cards, streak counter, and top languages for `@Piyarul7290`.
   - Core analytics methodology roadmap based on W. Edwards Deming's philosophy.

6. **📬 Interactive Contact Hub**:
   - Contact form with instant feedback and celebratory confetti animation.
   - Direct email copying for `piyarusekh7290@gmail.com`.
   - Verified links to LinkedIn, GitHub, and location.

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [Vite 6](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with Cyber Analytics Dark Theme
- **Data Visualizations**: [Recharts](https://recharts.org/) (Area, Bar, Line, Pie, Radar)
- **Icons**: [Lucide React](https://lucide.dev/) + Custom Brand SVGs
- **Delight & Animations**: `canvas-confetti` + Tailwind Transitions
- **Deployment**: Production-ready bundle (`dist/`) suitable for Vercel, Netlify, or GitHub Pages.

## 🚀 Quick Start Guide

### 1. Prerequisites
- **Node.js** (v18+ or v20+)
- **npm** or **pnpm**

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Production Build
```bash
npm run build
```
Generates optimized static assets inside the `dist/` folder.

### 4. Preview Production Build Locally
```bash
npm run preview
```

## 🌐 Deploy to Vercel or Netlify in 1-Click

### Deploying on Vercel:
1. Push this repository to your GitHub account: `https://github.com/Piyarul7290/portfolio`
2. Go to [vercel.com](https://vercel.com) and import the repository.
3. Framework Preset: **Vite**
4. Build Command: `npm run build`
5. Output Directory: `dist`
6. Click **Deploy**!
